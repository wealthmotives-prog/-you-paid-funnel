Security & data practices

Trust should be designed into the system.

You Paid expects to handle sensitive employment and verification information. This page explains the controls and principles we are building around that responsibility. It is not a certification or claim of perfect security.

Authenticated member access

Member records are tied to authenticated user accounts rather than public identifiers.

Row-level access controls

The backend uses row-level security so ordinary members are intended to access their own protected records rather than another member's records.

Separate operator authorization

Administrative access is controlled through an authorized operator role. A hidden URL is not treated as the security mechanism.

Payment separation

Payment status and founder entitlements are stored separately from work-verification truth. Payment should never create or improve a verified work fact.

Auditability

Verification and entitlement structures are designed to preserve what changed, when it changed, and the event that caused the change.

Data minimization

The intended practice is to collect information necessary for identity, work verification, account operation, payments, support, and legal obligations rather than unrelated personal data.

Sensitive data

Some information requires a higher bar.

Employment dates, payroll-related evidence, work schedules, verification sources, payment records, and identity data can be sensitive. As integrations mature, You Paid should use the least-privileged access necessary, avoid exposing raw provider credentials, and limit who or what can modify verification outcomes.

Source provenance

Whenever practical, a verification event should retain information about where its evidence originated.

Correction path

Members need a way to challenge inaccurate information and receive a review outcome.

Retention discipline

Retention periods should eventually be defined by data category, operational need, legal obligations, and member rights rather than kept forever by default.

What this page does not claim

This page does not represent that You Paid has obtained a SOC 2 report, ISO certification, PCI certification, independent penetration-test certification, or any other third-party security certification unless and until that is separately published.
