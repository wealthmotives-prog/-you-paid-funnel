Product status

Built. Building. Unresolved.

You Paid is now being built as verified work-data infrastructure, not merely a profile screen. This page separates operational architecture from partner relationships that do not yet exist.

Status snapshot: October 10, 2026.

BUILT

Member authentication

Authenticated member accounts and member-specific records exist.

BUILT

Historical-event schema

Verification events now support underlying event dates, verification dates, source entity, evidence level, verification method, and historical-record flags.

BUILT

Verified Work Ledger

Employment records, verification events, monthly cycles, and audit history exist in the backend.

BUILT

Data-provider architecture

Provider organizations and member/provider authorization records now have dedicated backend structures.

BUILT

Dispute architecture

The backend can track consumer disputes from receipt through investigation, source contact, modification, deletion, or closure.

BUILT

Reporting-transmission staging

Destinations and transmissions can be separately tracked by type, period, format, send status, acknowledgement, rejection, correction, or withdrawal.

BUILT

Operator + founder infrastructure

Authorized operator access, founder tiers, terms acceptance, entitlement logic, and related monitoring are structured.

BUILDING

Historical ingestion workflow

The schema is ready; production-grade document, payroll, timekeeping, employer, gig, and bank-derived verification workflows still need to be completed.

BUILDING

Employer/data-provider onboarding

Public partner positioning exists; contractual, technical, and operational onboarding still needs to be productionized.

BUILDING

Secure payments + subscription billing

Founder payment architecture exists; live payment processing and recurring verification membership remain to be activated and tested.

BUILDING

Member dispute workflow

The dispute data model now exists; the full member-facing submission and investigation interface is being completed.

UNRESOLVED

Nationwide bureau furnishing

No specific Experian, Equifax, or TransUnion furnishing relationship is represented as live. Accepted data model, onboarding, format, and operational requirements still must be established.

UNRESOLVED

Specialty consumer-report pathway

Operating as or through a specialty consumer reporting framework is a strategic path under evaluation and would carry significant FCRA and operational obligations.

UNRESOLVED

External underwriting adoption

No lender, landlord, insurer, scoring model, or other decision-maker is currently represented as relying on You Paid records.

What changed strategically

Historical work is now a first-class product requirement.

The system is no longer being designed only to accumulate records after enrollment. It is being designed to verify qualifying historical work activity and preserve the difference between when the activity occurred and when You Paid verified it.

Next gates

1. Productionize historical evidence intake.
2. Activate secure payments.
3. Launch provider onboarding and agreements.
4. Ship member dispute/correction UI.
5. Begin formal data-destination conversations.
6. Validate accepted furnishing or specialty-reporting pathways.
