Product status

Built. Building. Unresolved.

This page exists so visitors can separate working infrastructure from product direction and future ambition.

Status snapshot: October 10, 2026.

BUILT

Member authentication

Members can create and sign in to You Paid accounts.

BUILT

Verified Work Ledger structure

Employment records, verification events, monthly work cycles, and audit-history structures exist in the backend.

BUILT

Operator portal

Authorized operators can review defined records and monitor member/founder activity.

BUILT

Founding Access framework

Founder tiers, selections, terms acceptance, entitlements, upgrades, and payment-event architecture are structured.

BUILDING

Secure payment activation

The surrounding payment architecture exists, but live payment processing should not be treated as active until the real payment rail is connected and tested.

BUILDING

Automated verification

Direct employer, payroll, timekeeping, or other source integrations are not represented as production-complete.

BUILDING

Correction workflow

The public standard is defined; the full member-facing correction/dispute workflow still needs to be completed.

UNRESOLVED

Consumer-report furnishing

No specific bureau-furnishing relationship is represented as live. Metro 2 fit and partner pathways remain unresolved.

UNRESOLVED

External underwriting acceptance

No lender, landlord, insurer, or scoring model is currently represented as relying on You Paid records.

How to read this page

Future intention is not current functionality.

When a feature moves from idea to prototype to production, this page should change with it. We would rather move a label from BUILDING to BUILT after testing than market a planned feature as if it already works.

Next gates

3. Ship member correction/dispute tooling.
4. Formalize subscription billing.
